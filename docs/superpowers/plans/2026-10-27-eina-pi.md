# Eina PI (secció 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web estàtica (i extensió de Chrome opcional) per triar competències específiques i criteris d'avaluació del currículum català i copiar-los, cel·la a cel·la, a la secció 5 d'un PI de Google Docs.

**Architecture:** Un script Python extreu el currículum del Decret 175/2022 a `site/dades/curriculum.json`. Les versions simplificades i el mapatge ESO→primària són JSON estàtics al costat. La web és HTML + JS vanilla (mòduls ES) sense build; la lògica pura (`estat.js`, `format.js`) es prova amb `node --test`. L'extensió MV3 només obre la web publicada al panell lateral.

**Tech Stack:** Python 3 (stdlib) + `pdftotext` (poppler) per a l'extracció; HTML/CSS/JS vanilla; Node ≥ 20 (`node --test`) per a proves; GitHub Pages via GitHub Actions; Chrome Manifest V3.

**Spec:** `docs/superpowers/specs/2026-10-27-eina-pi-design.md`

## Global Constraints

- L'eina **no accedeix mai** a Google Docs/Drive ni a cap API; zero `fetch` fora de `./dades/`. Cap servidor, cap compte, cap IA en temps d'execució.
- Cap camp per a dades de l'alumne (nom, diagnòstic…). L'únic input de context és matèria + curs (1r–4t ESO).
- La còpia és **només `text/plain`** (decisió de l'agent: és el que garanteix que Google Docs aplica l'estil de la cel·la de destí). Un element per paràgraf, separats per `\n`.
- Codis oficials sempre presents, també a la versió simplificada: CE com `CE2.` + text; criteri com `CE2.2` + text (format del PI d'exemple).
- Blocs i etiquetes exactes de la cel·la "Etapa i curs":
  - `ESO_1-3` → `ESO (1r, 2n i 3r)`; `ESO_4` → `ESO (4t)`
  - `PRI_C1` → `Primària, cicle inicial (1r i 2n)`; `PRI_C2` → `Primària, cicle mitjà (3r i 4t)`; `PRI_C3` → `Primària, cicle superior (5è i 6è)`
  - Diversos blocs s'uneixen amb `, ` i l'últim amb ` i `.
- Curs de l'alumne → bloc per defecte: 1r, 2n, 3r ESO → `ESO_1-3`; 4t ESO → `ESO_4`.
- Tots els criteris d'un bloc afegit surten **marcats per defecte**; el docent desmarca.
- Versió simplificada: un sol nivell, estat `pendent` fins que es valida (`validada`). Marca visible "pendent revisar".
- Matèries ESO v1: Llengua Catalana i Literatura, Llengua Castellana i Literatura, Llengua Estrangera, Matemàtiques, Biologia i Geologia, Física i Química, Ciències Socials: Geografia i Història, Educació Física, Educació Plàstica, Visual i Audiovisual, Música, Tecnologia i Digitalització, Educació en Valors Cívics i Ètics. Àrees primària: Llengua Catalana i Literatura, Llengua Castellana i Literatura, Llengua Estrangera, Matemàtiques, Coneixement del Medi Natural, Social i Cultural, Educació Artística, Educació Física, Educació en Valors Cívics i Ètics.
- Tota la interfície en català.

## Review Focus

1. **Lletres perdudes en extreure el PDF** (p. ex. "isual", "atural", "obligat ria", "rees"): el JSON no pot contenir paraules mutilades; el validador les ha de rebutjar. → test a Task 1 i Task 2.
2. **Barreja ESO + primària amb codis coincidents** (CE1 d'ESO ≠ CE1 de primària): la còpia de CE i criteris ha de distingir l'etapa quan n'hi ha més d'una. → test a Task 4.
3. **Text lliure buit** o simplificada inexistent: s'ha de copiar l'oficial, mai una línia buida. → tests a Task 3 i Task 4.
4. **Tot desmarcat**: els botons de còpia no han de posar una cadena buida al porta-retalls; mostren "No hi ha res seleccionat". → test a Task 4 + comprovació a Task 5.
5. **Porta-retalls denegat** (context no segur, iframe de l'extensió sense permís): cal un missatge visible i fallback amb `document.execCommand('copy')`. → comprovació manual a Task 5 i Task 7.

### Esquema de dades (contracte entre tasques)

`curriculum.json`:
```json
{
  "blocs": { "ESO_1-3": "ESO (1r, 2n i 3r)", "...": "..." },
  "materies": [
    {
      "id": "eso.mat", "etapa": "ESO", "nom": "Matemàtiques",
      "ces": [ { "id": "eso.mat.CE1", "codi": "CE1", "text": "Interpretar, modelitzar..." } ],
      "criteris": [
        { "id": "eso.mat.ESO_1-3.1.1", "ce": "eso.mat.CE1", "codi": "CE1.1", "bloc": "ESO_1-3", "text": "Interpretar problemes matemàtics..." }
      ]
    }
  ]
}
```
Ids de matèria: prefix `eso.` o `pri.` + sigla (`cat`, `cas`, `est`, `mat`, `bio`, `fiq`, `cs`, `ef`, `epva`, `mus`, `tec`, `val`; primària `cat`, `cas`, `est`, `mat`, `medi`, `art`, `ef`, `val`).

`simplificades.json`: `{ "<criteriId>": { "text": "CE1.1 ...sense codi...", "estat": "pendent" | "validada" } }` — el `text` **no** porta codi (el format l'hi afegeix).

`mapatge.json`: `{ "eso.bio": "pri.medi", "eso.fiq": "pri.medi", "eso.cs": "pri.medi", "eso.tec": "pri.medi", "eso.epva": "pri.art", "eso.mus": "pri.art", "eso.cat": "pri.cat", "eso.cas": "pri.cas", "eso.est": "pri.est", "eso.mat": "pri.mat", "eso.ef": "pri.ef", "eso.val": "pri.val" }`

### Task 3: Lògica de selecció (`estat.js`)

**Files:**
- Create: `site/estat.js`, `site/estat.test.mjs`, `site/dades/mapatge.json`

**Interfaces:**
- Consumes: esquema de `curriculum.json`, `simplificades.json`, `mapatge.json`.
- Produces (tot pur, sense DOM):
  - `blocPerCurs(curs: 1|2|3|4) -> "ESO_1-3"|"ESO_4"`
  - `areaPrimaria(mapatge, materiaId) -> string|null`
  - `novaSeleccio(curriculum, materiaId, curs) -> Seleccio` — afegeix el bloc del curs amb tots els criteris marcats.
  - `afegeixBloc(sel, curriculum, materiaId, bloc) -> Seleccio` — afegeix tots els criteris d'aquell bloc marcats; idempotent.
  - `treuBloc(sel, materiaId, bloc) -> Seleccio`
  - `commuta(sel, criteriId) -> Seleccio`; `marcaBloc(sel, materiaId, bloc, marcat: boolean) -> Seleccio`
  - `posaVersio(sel, criteriId, "oficial"|"simplificada"|"lliure", textLliure?) -> Seleccio`; `posaVersioTots(sel, versio) -> Seleccio`
  - `criterisMarcats(sel, curriculum, simplificades) -> Array<{criteri, materia, text}>` — `text` ja resolt segons versió, sense codi.
  - `Seleccio = { blocs: Array<{materiaId, bloc}>, items: Record<criteriId, {marcat: boolean, versio, textLliure?: string}> }` (objecte immutable; cada funció en retorna un de nou).

Disseny de pantalla (estret, pensat per a panell lateral de ~360 px i també per a pestanya):
1. Capçalera: selector **Matèria** (només ESO) i **Curs de l'alumne** (1r–4t ESO). Interruptor global **Oficial / Simplificada**.
2. Llista de criteris del bloc, agrupats per CE (títol de la CE, no seleccionable). Cada criteri: casella, codi, text; botons petits `Oficial | Simplificada | Edita`. 4. "Afegeix criteris de…": selector amb els blocs que falten (l'altre bloc d'ESO i `PRI_C1/C2/C3`). Per a primària, selector d'**àrea** preseleccionat amb `areaPrimaria`, canviable.
5. Peu fix: tres botons **Copia CE**, **Copia criteris**, **Copia etapa i curs**, amb vista prèvia plegable de cada text. Feedback al botó: "Copiat ✓" / "No hi ha res seleccionat" / "No s'ha pogut copiar: selecciona el text de la vista prèvia i copia'l a mà".
